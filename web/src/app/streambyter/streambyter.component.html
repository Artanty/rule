ℹ️ About StreamByter

StreamByter is a MIDI processing script language for iOS/macOS. These scripts can be used in:

  • MIDI Messenger - Built-in StreamByter support
  • MIDI Flow - Advanced MIDI routing
  • AUM - Audio Unit Mixer with MIDI processing
  • Other apps that support StreamByter format

Note: Delay parameters may require advanced scripting techniques. The .sbr format is compatible with Audeonic Apps.

💡 Device names and CC/Note names are loaded from your MIDI Messenger settings!

✨ Click "🎨 name" to auto-generate rule names based on trigger/output settings!

🎯 Value Range allows you to trigger only when CC value is between min and max!

✏️ Custom Rules let you write raw StreamByter code that won't be parsed or modified!
